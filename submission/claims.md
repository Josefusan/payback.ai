## How to read this file

- **Evidence** = a repo path `file:line`, or a command whose output lands in `evals/out/*.json`.
- **Status**
  - `BACKED` — evidence exists today and supports the claim as written.
  - `PARTIAL` — some evidence exists, but the claim is broader than what is proven (usually a "live/works"
    nuance; the code path exists but has not run against the sandbox / real Clef yet).
  - `UNBACKED` — no evidence path exists today.
- **Action** — `KEEP` · `REWORD` (text too strong for the evidence) · `SCHEDULE <task-id> <gate>` ·
  `REMOVE`. Where a claim is UNBACKED the ledger names the task that must produce the evidence, or the task
  that must delete the claim.
- **Working-tree note (2026-10-06).** Paths point at the current working tree; some L2 files
  (`apps/worker/src/decision-provider.ts`, `.../paypal.test.ts`, `.../decision-provider.test.ts`) are untracked
